# C 语言基础复习：面向 BMS 的数据处理练习

这一组练习用于补充结构体之前的学习经历。代码不追求把语法全部抄一遍，而是用电芯采样数据把知识串起来。

## 学习顺序

1. `01-types-conditions`：整数、浮点数、布尔值、常量、条件组合和输入范围判断。
2. `02-loops`：用 `for` 统计采样序列，用 `while` 跟踪连续异常区间。
3. `03-functions`：拆分统计函数，让 `main` 只负责组织流程。
4. `04-arrays`：保存一段采样窗口，计算相邻变化和突变点。
5. `05-strings`：处理电芯标签、比较字符串和生成状态文本。
6. `06-pointers`：用指针遍历数组、原地限幅，并通过指针返回结果。

## 编译方式

在每个练习目录中运行：

```text
gcc -std=c11 -Wall -Wextra -pedantic main.c -o demo
```

Windows 下运行：

```text
.\demo.exe
```

## 完成标准

- 先不看答案，自己写一遍。
- 修改至少两组输入数据，观察输出变化。
- 给程序增加一个边界条件。
- 在对应的学习日志中记录“输入、输出、问题、下一步”。

## 和后续 BMS 的连接

这些程序还没有使用结构体、文件和动态内存，但已经在处理真实 BMS 中常见的问题：采样范围检查、异常判断、统计窗口、电芯标签和原地数据修正。完成这一组后，再回到 `C/01-structs` 学习如何把这些数据组织成 `Cell` 和 `BatteryPack`。
